# 수영대회 조 편성 안내 페이지

마스터즈 수영대회 참가자가 휴대폰으로 QR 코드를 찍어 자기 경기 정보를 바로 찾을 수 있게 만든 웹 페이지입니다.

**사이트:** https://rue-e.github.io/asan-swim/

> ⚠️ **지금 올라가 있는 명단은 모두 가짜(더미) 데이터입니다.**
> 선수 이름 32명과 일부 팀 이름(물결, 돌핀스, 블루레인)은 시연용으로 지어낸 것이며, 실제 인물과 관계없습니다.

## 실제 사용

- **2026년 10월 25일 아산시 시장배 마스터즈 수영대회**에서 실제로 사용했습니다.
- 대회 당일에는 대회 측이 배포한 **실제 대회 요강(조 편성표 PDF)** 을 바탕으로, 전체 84개 조와 참가자 191명의 명단을 넣어 운영했습니다.
- 대회 측 수정본이 나온 뒤에는 바뀐 내용을 비교해 반영했고, 오타로 확인된 이름은 따로 바로잡았습니다.
- 대회가 끝난 뒤 개인정보 보호를 위해 실제 명단을 내리고, 지금의 예시 데이터로 바꿨습니다.

## 기능

| 탭 | 내용 |
|---|---|
| 검색 | 이름을 넣으면 그 선수의 출전 종목, 조, 레인, 경기 시간을 카드 한 장에 모아서 보여 줌. 팀 이름으로 검색하면 팀원 전체가 나옴 |
| 시간표 | 경기 순서와 시간. 대회 당일에는 진행 중인 경기에 표시가 붙음 |
| 조 편성 | 종목별, 남녀별 조와 레인 배정 |
| PDF | 조 편성표 PDF를 페이지 안에서 바로 보기 (여백을 잘라 휴대폰에서 크게 보이도록 함) |

- 휴대폰 뒤로 가기 버튼으로 이전 화면에 돌아갈 수 있음
- 우리 팀(NINE) 선수는 분홍색으로 강조
- 서버 없이 파일만으로 동작 (검색도 휴대폰 안에서 처리)

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 페이지 본체 (명단 데이터, 검색 기능, 디자인 포함) |
| `heatsheet.pdf` | 조 편성표 PDF (현재는 예시 데이터로 만든 파일) |
| `pdf.min.js`, `pdf.worker.min.js` | 페이지 안에서 PDF를 그려 주는 도구 ([PDF.js](https://mozilla.github.io/pdf.js/)) |

GitHub Pages로 배포합니다.
